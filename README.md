# LeadPilot Pro — комплект прототипа

## Что уже работает в интерфейсе
- Локальная CRM, поиск и сортировка лидов, приоритеты, статусы и заметки.
- Защита от дубликатов по названию/сайту.
- CSV-импорт/экспорт и JSON-резервная копия.
- Черновик сообщения на основе введённых фактов.
- Подключение к вашему backend через `API URL + /draft`.
- Раздел источников и конфигурация RSS; интерфейс честно показывает, что одно сохранение источника не запускает мониторинг.

## Что нужно для реального ИИ
1. Разместить backend на Node.js-хостинге (например, Render/Railway/Fly.io или собственный сервер).
2. В переменные окружения backend добавить `GEMINI_API_KEY`, `GEMINI_MODEL`, `ALLOWED_ORIGIN`.
3. Запустить `npm install && npm start`.
4. В интерфейсе открыть «Настройки ИИ» и указать адрес backend с `/api` в конце.
5. Проверить `/api/health`, затем сгенерировать черновик.

Ключ не вставлять в HTML и не выкладывать в публичный репозиторий. Бесплатные лимиты и цены провайдера могут меняться.

## RSS-проверка
Backend содержит endpoint `POST /api/rss/check`, который может читать до 20 RSS-лент за вызов. Чтобы включить, задайте `RSS_MONITOR_ENABLED=true`. В запросе передавайте `sources: [{name,url,keywords}]`, где keywords — строка через запятую. Endpoint пока выполняется по запросу, а не в фоне по расписанию.

Для настоящего мониторинга 24/7 добавьте планировщик (cron/worker), хранение ранее увиденных ссылок в БД, дедупликацию, алерты и мониторинг ошибок. Не собирайте данные вопреки условиям площадок; используйте официальные API/RSS/разрешённые интеграции. Поиск не гарантирует, что найденная публикация является покупательским намерением.

## Важные ограничения
- Текущая CRM хранит данные в localStorage одного браузера. Очистка данных браузера может их удалить.
- Нет автономного сканирования всего интернета, интеграции с мессенджерами/почтой, автоотправки или общей облачной базы.
- Автоматическая отправка отключена: человек проверяет факты и текст до контакта.
- Для многопользовательского коммерческого продукта нужны авторизация, база данных, журнал действий, лимиты запросов, защита от злоупотреблений и соответствие правилам приватности/рассылок.
